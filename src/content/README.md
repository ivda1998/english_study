# 커리큘럼 콘텐츠 작성 규격

주차 하나가 파일 하나입니다. `week-01.json` … 처럼 두 자리 번호를 쓰고,
이 폴더에 넣으면 앱이 자동으로 읽어갑니다(코드 수정 불필요).

검증은 다음 명령으로 합니다.

```bash
npm run validate:content
```

## 하루 분량

| 항목 | 규격 |
|---|---|
| 어휘 | 정확히 10개. 예문에 표제어가 들어가야 합니다(굴절형이면 원형이 보이도록). |
| 문법 | 포인트 1개 + 한국어 설명(20자 이상) + 예문 2개 이상 + 문항 5개 이상 |
| 독해 | 지문 1편(주차별 단어 수 범위) + 어휘주석 2개 이상 + 전체 해석 + 문항 3개 이상 |
| 듣기 | 안내문 + 스크립트 2줄 이상 + 문항 2개 이상 (+ 받아쓰기 문장) |
| 말하기 | 따라 읽기 2~3문장 + 바꿔 말하기 + 질문 5개 (+ 1분 말하기, 수학 말하기) |

## 꼭 지켜야 하는 규칙

- `days`는 5개이고 순서는 `mon, tue, wed, thu, fri` 입니다.
- `id`는 `w01d1` 형식이며 파일의 주차 번호와 맞아야 합니다.
- `speakingTopics` 5개는 확정된 30개 목록(`src/content/topics.ts`)과 문구·순서가 같아야 합니다.
- **1분 말하기(`oneMinute`)는 화·목·금에만** 넣습니다. 월·수는 넣으면 안 됩니다.
- `oneMinute.topic`은 그 주 주제 5개 중 하나여야 하고, `keywords`는 정확히 5개입니다.
- **수학 연결 말하기(`mathTalk`)는 주 1회 이상** 넣습니다. `basic`과 `upgraded`는 각각 3문장입니다.
- 따라 읽기(`shadowing`) 문장은 그날 지문 본문에 그대로 들어 있어야 합니다.
- 객관식 정답은 0부터 세는 인덱스이고, 보기는 서로 달라야 합니다.
- 모든 채점 문항에는 한국어 해설을 답니다.

## 지문 길이 (주차별, 단어 수)

| 주차 | 범위 |
|---|---|
| 1 | 95 ~ 130 |
| 2 | 105 ~ 140 |
| 3 | 115 ~ 150 |
| 4 | 125 ~ 160 |
| 5 | 135 ~ 172 |
| 6 | 150 ~ 195 |

## 문항 종류

```jsonc
// 4지선다
{ "kind": "choice", "id": "w01d1-g1", "prompt": "…", "options": ["…"], "answer": 0, "explanation": "…" }

// 단답 (대소문자·문장부호는 무시하고 채점)
{ "kind": "write", "id": "…", "prompt": "…", "accept": ["has lived"], "explanation": "…", "hint": "…" }

// 채점하지 않는 자기 서술
{ "kind": "free", "id": "…", "prompt": "…", "sample": "…" }
```

앱의 **설정 → 주차 콘텐츠 가져오기**에서 이 형식의 JSON을 붙여넣으면
빌드 없이 바로 같은 번호의 주차를 대신하게 할 수 있습니다.
